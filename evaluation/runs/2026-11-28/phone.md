# Try the nine Hansard questions on a phone

Use ChatGPT Voice on Android in a fresh personal chat. Paste the directory URL below as text before switching on Voice. It identifies the November snapshot by Git commit. The directory also contains links to the rolling Pages site. If the AI follows them, ask it to read back the snapshot identifier. The live homepage alone cannot establish a release pin.

https://raw.githubusercontent.com/chris-page-gov/okf-hansard/41a340e06ec02b7d5d4d5802e893534697328d32/november/hansard.json

Say “Use this Hansard release to answer my questions. Tell me which bundle file you opened and give the contribution link. If you use official Hansard or another source directly, say which part of the answer came from it.”

Ask each question in a separate turn. Start a fresh chat for each persona when practicable and paste the same directory again. Keep an initial failure and any assisted retry as separate results. The transcript and its citations are enough to review the run. Use only fictional persona details.

## A parent or carer

**P1-Q1** What did Nadia Whittome ask about parents' independent appeal rights on 16 November 2026, and what did the Minister actually answer?

**P1-Q2** Which appeal rights under the existing EHCP framework are in force, and which aspects of Individual Support Plans remain proposals? Cite primary legal and parliamentary sources; mark any external sources.

**P1-Q3** Which earlier parliamentary contributions specifically address SEND appeal rights, and how do their positions compare with the 16 November exchange?

## A parliamentary researcher

**P2-Q1** Locate the exact 16 November contribution on SEND appeal rights and return its speaker, date, House, stable contribution identifier and source link.

**P2-Q2** Trace backwards from that contribution to earlier discussions of independent SEND appeal rights. For each link, identify the matching entity/predicate and quote or locate the supporting evidence span.

**P2-Q3** Which apparent historical links are only lexical mentions of SEND, EHCPs or appeals rather than evidence of the same legal question? Explain exclusions and coverage gaps.

## A citizen or journalist

**P3-Q1** What were the main subjects covered in both Houses on Monday 16 November 2026, and what is the completeness boundary of this summary?

**P3-Q2** What was said in the Commons about the Microsoft 365 outage on 16 November, by whom, and what was established versus merely asserted?

**P3-Q3** How does Monday's discussion of NHS digital capability connect to Tuesday's Palantir/Federated Data Platform debate? Distinguish explicit references from shared entity mentions.

## Check where the answer came from

A correct summary and a working Hansard link can both come from ordinary web search. For the assisted SEND test, give the AI the pinned monthly concept file below. Ask it to return both Nadia Whittome identifiers on 16 November, then open the relevant Hansard passage. The concept file gives dates, names and locators. Read the official contributions for the words of the question and reply.

https://raw.githubusercontent.com/chris-page-gov/okf-hansard/41a340e06ec02b7d5d4d5802e893534697328d32/november/history/send-reform.month.json

Record the supplied URL, what the AI says it opened, any returned record identifiers, its original answer and visible source links. A retrieval claim alone is weaker than a fetch receipt. Allow a link-opening failure to stand. The assessor can check the answer against the references after the conversation.
