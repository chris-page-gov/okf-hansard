A week in Parliament Phone Voice demo

Contributor tour

Follow one Railways Bill question from the phone Voice demo to the evidence, the source code and the checks that run before publication.

On this tour

  1. Ask about the Railways Bill
  2. Find the evidence your AI used
  3. Follow a link back to Parliament

1. Ask about the Railways Bill

Ask your AI which House considered Bill 4030 at Report stage on 18 November 2026, and ask it for the exact Hansard link. The worked evidence identifies the House of Lords and records debate on that day.

  • Open the Railways Bill companion
  • Read the official Lords Report stage debate
  • Read the phone demo guide in the repository

2. Find the evidence your AI used

The public collection describes what is available and where to find the records. The Read OKF+ skill guides compatible clients to open the coverage and relevant passages before answering. If an assistant cannot open links, copy evidence from the phone finder into the conversation.

  • Find and copy public evidence
  • Read the machine-readable collection directory
  • Inspect the Read OKF+ skill source
  • Inspect the retrieval contract

3. Follow a link back to Parliament

Capture code reads the official records for each House. The history index stores source locators for earlier matches. The read-only MCP server uses the query index so an assistant can open the exact passage. A match by name or alias is evidence of a mention and needs context to establish a stronger claim.

  • Inspect the sitting capture code
  • Inspect the historical index code
  • Inspect the evidence query code
  • Inspect the read-only MCP server

4. Check how the bundle was verified

The November publisher checks the sitting capture and graph assertions before replacing the public files. Read the coverage report for the dated snapshot and verification result. The checksum list lets clients compare the published bytes with those checked by the publisher.

  • Read the published coverage and verification report
  • Check the November file hashes
  • Inspect the verification code
  • Inspect the November publisher

5. Reuse the bundle or contribute

Open the OKF 0.3 Markdown to see portable concepts and source links. Use OKF Explorer to follow parliamentary relationships and dates. The repository guide explains how to reproduce the build and check your work.

  • Read the November OKF Markdown index
  • Explore the November timeline and earlier mentions
  • Read the maintainer guide
